# Guangya storage provider

独立 HTTP 媒体源插件。Node.js 24，无第三方运行依赖。不启动 hack-guangya 主应用、不读取它的 SQLite，不挂载文件系统、不下载视频。

## 运行

FBZ 与插件配置同一个至少 32 字符的随机 `FBZ_STORAGE_PLUGIN_KEY`；FBZ 另需独立 `FBZ_SECRET_KEY` 用于数据库凭据加密。两个密钥应通过部署 secret/环境注入，妥善保存；丢失加密密钥将无法恢复已存账号。

```powershell
# 先在当前进程配置 FBZ_STORAGE_PLUGIN_KEY，然后运行：
node server.mjs
```

默认监听 127.0.0.1:8098。FBZ 配置 `FBZ_GUANGYA_PLUGIN_URL=http://127.0.0.1:8098/rpc`。容器部署可以使用 compose.yaml；跨主机通信请使用 HTTPS 和受限网络，不把插件端口公开给播放器。

旧账号仍可通过兼容管理入口使用 `/rpc`。安装并启用光鸭插件包后，后台侧栏出现光鸭网盘入口，可接管旧账号，再通过插件页管理扫码、挂载和媒体库。HTTP 插件进程需要按部署说明单独启动。

## 已实现

- 加密账号、设备授权登录、身份确认、刷新令牌、断开和旧授权任务失效。
- 分页目录、按账号限速、跨 FBZ 进程的数据库行锁、断点扫描与完整扫描后的缺失标记。
- 电影 NFO、剧/季/集层级、标题/简介/年份/时长/外部 ID/题材，海报和背景图、同名外挂字幕。
- 按需 302；播放入口继续使用 FBZ 权限校验与进度接口。直链按账号和凭据版本缓存，不持久化到媒体库。
- 小文件读取限制、逐跳校验、DNS 公网地址检查与连接时固定检查过的解析结果；不转发 OAuth token 到 CDN。

首版单账号请求串行，默认 10 QPS（可配置 1–20，通常使用 10–20）。多个 FBZ 进程共享数据库锁，插件内部刷新/重试同样排队。未实现分布式优先级调度、自动探测最佳 QPS、云端转码或整片视频中转；失败扫描保留断点，手工继续。云端视频无可靠技术信息时不批量 ffprobe，NFO 缺少时长会保留未知。

当前为只读媒体源，不具备上传、移动、删除云盘文件的 RPC。账号断开保留索引；已发出的 CDN URL 在真实过期前可能继续可用。浏览器是否可直放取决于 CDN CORS 和编码支持，原生客户端的过期 URL 重试也需实测。

## 测试

`node --test provider.test.mjs` 测试缓存、限流、刷新、账号隔离和安全边界。

`fixture-server.mjs` 是单独启动的离线接口，仅监听 8099，返回明确的测试内容与 fixture.invalid URL。它不会连接真实光鸭，生产 server.mjs 不引用它。配合 FBZ 的独立测试库和 `scripts/smoke-storage.ps1` 验证加密保存、NFO/图片/字幕入库、302、401 与进度落库；这不等于真实 CDN 视频播放验证。

`guangya-protocol.mjs` 复用用户自有 hack-guangya 项目的协议适配模块（核查基线 25949c1）。不含用户账号凭据；客户端协议配置可通过该模块支持的环境变量替换。

真实验收已完成扫码绑定、指定 Media Library 扫描、4K MP4 网页播放与 16.91552 秒断点恢复；MKV 样片网页失败但 FFmpeg 解码成功。完整证据见 ../../../../docs/GUANGYA_STORAGE_PLUGIN_DESIGN.md（仓库根 docs）。

## 挂载分离与刷新

新版入口是插件配置弹窗。挂载只登记云端目录与 `/cloud/...` 地址，媒体库页面负责关联和资料策略。0079 升级保留已有索引与关联；定时刷新默认每 60 分钟，可设 0 关闭。失败退避续扫。NFO 支持云端既有资料或文件名；图片支持预缓存/按需缓存。此版不含在线刮削器接入。
## 可安装插件包（2026-10-05）

本目录现在提供 `manifest.json` 与 `ui/index.html`，可用仓库 `scripts/package-plugin.ps1` 打包后按插件市场生命周期安装、审批、启用。进程的 `/fbz-plugin` 入口校验 FBZ HMAC 签名；`/rpc` 仍用于旧账号迁移前的兼容模式。插件页显示扫码与挂载管理，旧账号可在新插件进程签名验证通过后接管；媒体、进度与密文保持原有 ID 和内容。宿主支持同一契约的其他网盘插件。见 `fbz-api/docs/plugin-system.md` 的页面与存储源协议。
