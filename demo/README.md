# AetherNAS 家庭影音库原型（归档）

这是从设计稿迁移过来的静态 Web 原型，可直接打开 `index.html` 查看。

## 页面

- 首页：观影入口、继续观看、新入库电影、热门分类
- 影视详情：播放入口、剧集列表、技术信息
- 管理后台：存储、活动、用户权限
- 组件规范：颜色、形状、排版与组件角色说明

## 文件

- `index.html`：页面入口
- `styles.css`：设计系统与响应式布局
- `app.js`：页面数据、导航切换与渲染
- `assets/`：影视背景、海报与封面素材
