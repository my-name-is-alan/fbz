## 浏览器媒体链路

优先直接访问云盘播放入口。远端 CORS 不满足重封装需求时，使用 FBZ 的受保护 Range 中继，再回退浏览器原生播放。中继只接受已登记且有权限的云盘媒体：单次最多 32 MiB、最多 8 个并发、背压流式传输；HTTPS、公网地址校验、DNS 固定与逐跳检查，不转发账号授权到 CDN。它不整片下载，也不执行服务端转码。

播放器源码固定在 upstream commit `d3bbbfcf7717a5107e1a6552453ee5b8f915d7d1`。原始源码及许可证在 `fbz-fe/vendor/webplayer`；`scripts/build-webplayer.mjs` 生成运行资源并应用路径和资源释放补丁。FFmpeg WASM 按需加载，相关许可和来源见 NOTICE.md。

## 已验证

- 前端格式、lint、类型检查通过；5 个测试文件共 16 项通过；生产构建通过。
- Rust Range 边界及非公网目标测试 2 项通过，API 构建通过。实测中继未授权返回 401、过大区间返回 416，合法 1024 字节请求返回 206。
- 浏览器 1440、768、390 宽度检查，无横向溢出；深浅主题、手机弹窗、年份筛选、无结果重置与剧集详情已检查。
